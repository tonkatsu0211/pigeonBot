Bot一覧songGuessNK利用規約プライバシーポリシー

利用規約

最終更新日: 2026年10月29日

この利用規約(以下「本規約」)は、tonkatsu0211(以下「運営者」)が提供するDiscord Bot「songGuessNK」(以下「本Bot」)の利用条件を定めるものです。本Botをサーバーに招待した方、または本Botの機能を利用した方は、本規約に同意したものとみなします。

第1条(本Botについて)

本Botは、Discordのサーバー上で曲名当てクイズを遊べるDiscord Botです。個人の趣味として無償で提供しており、機能は予告なく追加・変更・終了することがあります。

  • /quiz: 出題者が入力した曲名を、同じ文字は同じ番号になる形式(例: ①②③ ④⑤⑥④⑦)に変換して出題します。サーバー内のチャンネルでのみ使えます。
  • sg_答え: 答えを回答します。
  • sg!open n: n番の文字を公開します。
  • sg!leaderboard: サーバーごとのランキングを表示します。
  • /help: コマンド一覧を表示します。
  • /ping: botの応答速度を計測します。

第2条(利用条件)

  1. 本Botの利用には、Discordの利用規約およびコミュニティガイドラインの遵守が必要です。
  2. Discordの年齢要件を満たしていない方は、本Botを利用できません。
  3. サーバーに本Botを招待できるのは、そのサーバーで必要な権限を持つ方に限ります。

第3条(禁止事項)

本Botの利用にあたり、次の行為を禁止します。

  • 法令または公序良俗に反する行為
  • 複数のアカウントや自動化ツールを使って、回答や得点、ランキングを不正に操作する行為
  • sg!open 後の回答・公開の制限を回避する行為
  • 本Botに過度な負荷をかける行為(コマンドの連続送信など)
  • 本Botの不具合や脆弱性を悪用する行為
  • 本Botの運営を妨害する行為
  • 他の利用者や第三者に迷惑・不利益を与える行為
  • その他、運営者が不適切と判断する行為

第4条(ゲームのルールと得点)

  1. 出題は、1つのチャンネルにつき同時に1問までです。
  2. 出題者は、自分が出した問題で sg_ と sg!open を使えません。
  3. sg!open をした人は、他の人が sg!open をするか、2分が経過するまで、回答と次の sg!open ができません。
  4. 正解したときの得点は、「まだ開かれていない文字の種類数(同じ文字は1種類と数えます)」に、曲名の文字数(スペースを除く)に応じたボーナス倍率を掛けた値です。倍率は、1文字で10倍、2文字で6倍、3文字で4倍、4文字で3倍、5文字以上で等倍です。
  5. 出題者の得点は、開かれた文字の数(同じ文字は1つと数えます)に、不正解の回答の回数を足した値です。正解が出たときも、全ての文字が公開されて正解者なしで終了したときも、同じ方法で計算します。ボーナス倍率は掛けません。
  6. 回答の判定では、大文字と小文字、全角と半角、スペースの違いを区別しません。
  7. 得点に金銭的な価値はなく、景品や報酬と交換することもできません。運営者は、不具合の修正や不正への対応のため、得点やランキングを修正・リセットすることがあります。

第5条(出題内容)

  1. 曲名は出題者が入力します。運営者は、入力された曲名が実在するか、正しいかを確認しません。
  2. 曲名以外のもの(歌詞の一部、他人の個人情報、攻撃的な言葉など)を出題として入力しないでください。
  3. 出題内容についての責任は、出題者が負います。

第6条(メッセージの読み取りについて)

本Botは、閲覧できるチャンネルのメッセージを読み取りますが、処理するのは sg_、sg!open、sg!leaderboard で始まるメッセージだけです。読み取りを望まないサーバーの管理者は、本Botのチャンネル閲覧権限やメッセージ送信権限を制限するか、本Botをサーバーから退出させることで、読み取りを止められます。詳しくはプライバシーポリシーをご確認ください。

第7条(利用制限・提供停止)

運営者は、利用者が本規約に違反した場合、事前の通知なく、そのユーザーやサーバーでの本Botの利用を制限、得点の削除やランキングからの除外、または本Botをサーバーから退出させることがあります。また、メンテナンスや障害、その他の事情により、本Botの提供を一時的または恒久的に停止することがあります。

第8条(免責事項)

  1. 本Botは現状有姿で提供され、動作の正確性、完全性、有用性、継続的な稼働を保証しません。
  2. 障害や仕様変更により、得点や進行中のクイズのデータが消えたり、誤ったりすることがあります。
  3. 本Botの利用または利用不能により生じた損害について、運営者は故意または重過失がある場合を除き、責任を負いません。
  4. 利用者どうしのトラブルは、当事者間で解決してください。

第9条(規約の変更)

運営者は、必要に応じて本規約を変更できます。変更後の規約は、本ページに掲載した時点で効力を生じ、変更後に本Botを利用した場合は、変更後の規約に同意したものとみなします。
